# 📘 Учебные примеры на C++ — Упражнения 1–3

Ниже — описание трёх функций из файла `# include iostream.txt`. Для каждой функции дано её назначение, разбор ключевых моментов и замечания по коду. Полный код с точкой входа приведён в конце.

## 🔹 1. `Ex_one()` — расчёт стоимости билетов со скидкой

**Назначение:** запрашивает имя покупателя, количество билетов, цену одного билета и признак скидки (0 или 1), а затем валидирует данные и рассчитывает итоговую сумму.

**Разбор и замечания:**
- `const double stavka = 0.10;` — ставка скидки (10%), защищена от изменения.
- `std::getline(std::cin, name)` — читает имя целиком (с пробелами).
- Цепочка `std::cin >> ticket >> price_one >> discount_input` — последовательный ввод трёх значений.
- **Валидация в два этапа:**
  1. Проверка на «полный ноль» (0 билетов и нет скидки) — выводит `"Input error"`.
  2. Проверка диапазонов: билеты от 1 до 10, цена не ниже 5000, скидка строго 0 или 1 — иначе `"Invalid data"`.
- `bool has_discount = (discount_input == 1);` — преобразование ввода в `bool`.
- Тернарный оператор `has_discount ? base * stavka : 0.0` — элегантный расчёт скидки.
- ⚠️ **Опечатка в выводе:** `"Bace"` → `"Base"`, `"Discount applide"` → `"Discount applied"`, `"Input error"`/`"Invalid data"` — стиль разный, лучше унифицировать.
- ⚠️ `std::endl << "\n"` — двойной перевод строки (`endl` уже добавляет `\n`). Достаточно `"\n"`.
- ⚠️ `std::endl` медленнее, чем `"\n"`, так как сбрасывает буфер.
- 💡 `std::string name(" ");` — инициализация пробелом; лучше `std::string name;` (пустая строка).

## 🔹 2. `Ex_Two()` — анализ температурных показателей

**Назначение:** запрашивает количество измерений и сами значения, фильтрует некорректные, считает статистику (принято, отклонено, «рабочий диапазон» 0..40) и среднее арифметическое.

**Разбор и замечания:**
- `int count = 0;` — количество измерений.
- Проверка `count < 0 || count > 10` — ограничение на объём ввода.
- Цикл `for (int i = 0; i < count; i++)` — перебор измерений.
- `continue` — пропуск итерации для отклонённых значений (температура вне `[-50; 100]`).
- `sum += temp;` — накопление суммы для среднего.
- `working++` — счётчик «рабочего» диапазона `[0; 40]`.
- Тернарный оператор с `std::to_string` — аккуратный вывод среднего или `"n/a"`, если ничего не принято.
- ⚠️ **Опечатка:** `"Assepted"` → `"Accepted"`, `"Bace"` в первом упражнении — та же тема.
- ⚠️ Деление `sum / accepted` — тип `double`, но `sum` объявлен как `double`, поэтому результат корректный. Если бы `sum` был `int`, потребовался бы `static_cast<double>`.
- 💡 Логика «рабочего диапазона» неочевидна из имени `working` — лучше `inWorkingRange` или комментарий.

## 🔹 3. `Ex_Three()` — учёт бюджета

**Назначение:** запрашивает бюджет, затем до 10 раз — цены товаров. Считает количество купленных товаров, потраченную сумму и остаток. Ввод `0` останавливает цикл.

**Разбор и замечания:**
- `const int limit = 100000;` — максимально допустимая цена/бюджет.
- Проверка `budget < 0 || budget > limit` — валидация бюджета.
- `for (int i = 0; i < 10; i++)` — ограничение на 10 товаров.
- `if (price == 0) break;` — досрочный выход по команде пользователя.
- `continue` — пропуск невалидной цены.
- ⚠️ **Критическая логическая ошибка:** условие `if (price > budget - spent)` означает «если цена БОЛЬШЕ остатка — добавить». Это противоположно логике! Должно быть `price <= budget - spent` (товар помещается в остаток).
- ⚠️ **Дублирование блока:** проверка `if (price < 0 || price > limit)` написана дважды подряд — второй блок недостижим и лишний.
- ⚠️ **Опечатка в выводе:** `"Added"` при успешном добавлении; логика сообщения сбита из-за ошибки выше.
- ⚠️ **Возврат значения:** `return 0;` находится **внутри `else`**, а не в конце функции. Если бюджет невалиден, функция **не возвращает ничего** → неопределённое поведение. Должно быть:
