# Разбор кода: Ввод, вывод, переменные и базовые операции

## Функция `age`

```cpp
int age(){
	int age{};
    std::cout << "Age: ";
    std::cin >> age;
    std::cout << "Age received: " << age << "\n";
    return 0;
}
```

Ожидаемый вывод:

```
Age: 25
Age received: 25
```

Теория:
Перед нами первая функция. Функция — это именованная область кода, которая выполняет конкретную задачу. Представь её как отдельный механизм, который можно запустить, когда нужно. В данном случае функция называется `age` и возвращает целое число (`int`), хотя в реальности она просто возвращает 0, так как её главная цель — показать сообщение.

Внутри функции мы создаем переменную. Переменная — это именованная область памяти, в которую мы можем положить какие-то данные. Строчка `int age{};` создает переменную с именем `age` типа `int` (целое число) и с помощью фигурных скобок сразу инициализирует её нулём. Это современный и безопасный способ объявления, чтобы в памяти не осталось случайного мусора.

Дальше мы видим конструкцию `std::cout`. Что такое `std`? Это пространство имён (namespace). В C++ очень много готовых функций и классов, и чтобы они не конфликтовали друг с другом по именам, их сгруппировали. `std` — это стандартная библиотека. `cout` — это поток вывода на экран (character output). Оператор `<<` как бы «направляет» текст в этот поток. Мы пишем `std::cout << "Age: ";`, и на экране появляется приглашение ко вводу.

Затем работает `std::cin` — поток ввода с клавиатуры (character input). Оператор `>>` забирает данные из потока и кладет их в нашу переменную `age`. Программа останавливается и ждет, пока пользователь не введет число и не нажмет Enter. После этого мы снова используем `std::cout`, чтобы показать, что данные получены. Символ `\n` — это управляющий символ переноса строки, чтобы следующий вывод не прилипал к текущему.

Проверяется здесь базовая механика взаимодействия с пользователем. Это легко освоить, потому что мы просто просим данные, кладем их в «коробочку» и показываем результат.

## Функция `tasc`

```cpp
int tasc() {
	const double serviceFee{ 20.0 };
	double portionPrice{};
	int portionCount{};

	std::cout << "Prise and portions: ";
	std::cin >> portionPrice >> portionCount;
	double total{ portionPrice * portionCount * serviceFee };
	std::cout << "Total: " << total << " RUB\n";

	return 0;
}
```

Ожидаемый вывод (при вводе 100 и 2):

```
Prise and portions: 100 2
Total: 4000 RUB
```

Теория:
Здесь мы знакомимся с типами данных и константами. Переменная `serviceFee` объявлена как `const double`. Константа (`const`) — это переменная, значение которой запрещено менять после инициализации. Если попытаться это сделать, программа не скомпилируется. Тип `double` означает число с плавающей точкой (дробное). Переменная `portionCount` имеет тип `int`, то есть целое число.

Обрати внимание на ввод: `std::cin >> portionPrice >> portionCount;`. Это цепочка. Программа сначала ждет первое число для цены, затем второе для количества. Они разделяются пробелом или Enter.

Далее происходит вычисление: `double total{ portionPrice * portionCount * serviceFee };`. Сначала перемножаются цена и количество, а потом результат умножается на `serviceFee`.

Важный момент: В данном коде заложена логическая ошибка. Если `serviceFee` — это сервисный сбор в размере 20%, то математически правильная формула должна быть `portionPrice * portionCount * (1 + serviceFee / 100)`. В текущем виде программа умножает сумму на 20, что дает колоссальный и неверный итог. Тем не менее, с точки зрения синтаксиса и работы с памятью, код написан верно, и он отлично демонстрирует, как переменные разного типа (дробные и целые) могут взаимодействовать в одном выражении.

## Функция `discret`

```cpp
int discret() {
	bool ready{};

	std::cout << "Ready (0 or 1): ";
	std::cin >> ready;
	std::cout << "Ready: " << std::boolalpha << ready << "\n";

	return 0;
}
```

Ожидаемый вывод (при вводе 1):

```
Ready (0 or 1): 1
Ready: true
```

Теория:
Здесь мы работаем с логическим типом данных `bool`. Логический тип — это тип, который может принимать только два значения: `true` (истина) или `false` (ложь). В памяти он обычно занимает один байт. При вводе с клавиатуры число 0 воспринимается как `false`, а любое ненулевое число (обычно 1) — как `true`.

Особенность вывода логических значений заключается в том, что по умолчанию `std::cout` печатает их как числа 0 и 1. Чтобы увидеть слова `true` и `false`, мы используем манипулятор `std::boolalpha`. Манипулятор — это специальная команда, которая меняет настройки потока вывода. Он говорит потоку: «все последующие логические значения выводи текстом». Это делает вывод гораздо более читаемым для человека. Освоить это легко, так как это простое переключение формата отображения данных.

## Функция `thory_one`

```cpp
int thory_one() {
	std::string name;
	std::string message{ "Hello METANIT.COM!" };
	std::string message2 = "Hello METANIT.COM!";
	std::string message3("Hello METANIT.COM");

	return 0;

```

Ожидаемый вывод (при вводе Ivan):

```
Ivan
Name: Ivan
```

Теория:
Здесь в игру вступают строки. Строка — это последовательность символов. В C++ для удобной работы с текстом используется класс `std::string`. Чтобы им пользоваться, в начале программы обязательно должна быть подключена библиотека `<string>`.

В коде показаны три способа создания строки:

- `std::string message{ "..." };` — списковая инициализация (современный стиль).
- `std::string message2 = "..." ;` — копирующая инициализация (как в старых версиях C).
- `std::string message3("...");` — прямая инициализация через вызов конструктора.

Все три способа работают одинаково и создают строку с текстом. Однако для ввода строки с клавиатуры используется `std::cin >> name`. У этого подхода есть ограничение: оператор `>>` читает текст до первого пробела. Если ты введешь «Ivan Petrov», в переменную `name` попадет только «Ivan», а остаток останется в буфере ввода. Для чтения строк с пробелами используется другая функция — `std::getline`, которая встретится нам дальше. Понимание этого механизма критически важно, чтобы не удивляться, почему программа «съедает» только часть введенного текста.

Теория:
Эта функция объединяет в себе всё, что мы прошли ранее, и добавляет важный нюанс работы с вводом строк. Мы используем `std::getline(std::cin >> std::ws, name)`.
Функция `std::getline` читает всю строку целиком, включая пробелы, до символа переноса строки (`\n`). Это то, что нам нужно для ввода имени и названия курса.
Но зачем здесь `std::cin >> std::ws`? Манипулятор `std::ws` (whitespace) удаляет все ведущие пробельные символы (пробелы, табуляции и, главное, оставшиеся символы переноса строки) из входного потока. Без него `getline` может сразу же прочитать пустую строку, если перед этим в потоке остался «висящий» Enter от предыдущего ввода. Это классическая ловушка для новичков.

Далее мы вводим числа и логическое значение, используя уже знакомый `std::cin`. Вычисляем общее время в переменной `Total`.

Важное замечание по коду: Переменная `Total` вычисляется, но нигде не выводится на экран. Кроме того, в командах вывода отсутствуют пробелы между текстом и переменными: `std::cout << "Name" << name << "\n";` выведет слипшуюся строку `NameIvan Petrov`. Эти мелкие недочеты не ломают программу, но портят впечатление от результата. Тем не менее, как учебный пример, эта функция отлично показывает, как работают разные типы ввода в одном сценарии.

## Функция `dicriment`

```cpp
int dicriment() {
	int a{ 8 };
	int b{ a-- };
	std::cout << "a = " << a << std::endl;
	std::cout << "b = " << b << std::endl;

	return 0;
}
```

Ожидаемый вывод:

```
a = 7
b = 8
```

Теория:
Здесь мы разбираем операторы инкремента и декремента. Инкремент (`++`) — это операция увеличения значения переменной на единицу. Декремент (`--`) — операция уменьшения на единицу. Эти операторы бывают префиксными и постфиксными. В данном случае используется постфиксный декремент: `a--`.

Как это работает: когда мы пишем `int b{ a-- };`, компилятор сначала берет текущее значение переменной `a` (то есть 8) и присваивает его переменной `b`. И только после этого, когда значение уже скопировано, он уменьшает `a` на единицу (становится 7). Поэтому в итоге мы видим `a = 7`, а `b = 8`.

Если бы мы написали `int b{ --a };` (префиксный декремент), то `a` сначала уменьшилось бы до 7, и это же значение попало бы в `b`. В этом и заключается тонкая разница, которую легко запомнить: постфиксный оператор отдает старое значение, а префиксный — новое. В выводе здесь используется `std::endl`, который делает то же самое, что и `\n`, но дополнительно сбрасывает буфер вывода (делает так, чтобы текст появился на экране мгновенно).

## Функция `calculator`

```cpp
int calculator() {
	int num1;
	int num2;
	char operation;

	std::cout << "Первое число: ";
	std::cin >> num1;
	std::cout << "Второе число: ";
	std::cin >> num2;
	std::cout << "Операция: ";
	std::cin >> operation;

	if (operation == '+') {
		std::cout << "Результат: " << num1 + num2 << "\n";
	}
	else if (operation == '-') {
		std::cout << "Результат: " << num1 - num2 << "\n";
	}
	else if (operation == '*') {
		std::cout << "Результат: " << num1 * num2 << "\n";
	}
	else if (operation == '/') {
		if (num2 == 0) {
			std::cout << "Ошибка, потому что нельзя делить на 0" << "\n";
		}
		else {
			std::cout << "Результат: " << num1 / num2 << "\n";
		}
	}
	else {
		std::cout << "Неизвестная операция" << "\n";
	}
}
```

Ожидаемый вывод (пример для деления на ноль):

```
Первое число: 10
Второе число: 0
Операция: /
Ошибка, потому что нельзя делить на 0
```

Теория:
Этот блок посвящен условиям. Условие — это то обстоятельство, от которого зависит что-то. В рамках программирования на C++ это логическое выражение, которое проверяется на истинность (возвращает `true` или `false`). В зависимости от результата выполняется либо один блок кода, либо другой.

Для хранения символа операции мы используем тип `char` (character). Это простой тип данных, который хранит один символ. Символы заключаются в одинарные кавычки, например `'+'` или `'/'`.

Конструкция `if (operation == '+')` проверяет, равен ли введенный символ плюсу. Обрати внимание на двойное равно `==`. Это оператор сравнения. Одиночное `=` — это присваивание. Если случайно написать `if (operation = '+')`, программа не выдаст ошибку, но выполнит присваивание, и логика сломается.

Конструкция `else if` позволяет проверить несколько условий по очереди. Если первое условие ложно, проверяется следующее, и так далее. Когда мы доходим до деления, мы используем вложенное условие: `if (num2 == 0)`. Это проверка на безопасность, потому что делить на ноль в математике нельзя, а в программе это может привести к аварийному завершению. Если делитель равен нулю, мы выводим ошибку, иначе выполняем деление. Финальный `else` срабатывает, если ни один из символов не совпал с ожидаемыми. Это делает программу устойчивой к любым действиям пользователя.
