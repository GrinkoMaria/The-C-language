## 🔹 1. `age()` — ввод возраста

**Назначение:** запрашивает у пользователя возраст и выводит его обратно на экран.

**Разбор и замечания:**
- Внутри функции создаётся локальная переменная `int age{}`. Фигурные скобки обеспечивают инициализацию нулём (uniform initialization, C++11+). Это хорошая практика, так как переменная не содержит «мусор».
- `std::cin >> age` считывает целое число из стандартного ввода.
- ⚠️ Функция объявлена с типом `int`, но по смыслу она ничего не возвращает (кроме `0`). Лучше объявить её как `void age()`.

## 🔹 2. `tasc()` — расчёт стоимости порций

**Назначение:** считает итоговую сумму заказа: цена порции × количество × коэффициент.

**Разбор и замечания:**
- `const double serviceFee{ 20.0 }` — константа, которую нельзя изменить после инициализации. Хороший стиль.
- Цепочка `std::cin >> portionPrice >> portionCount` позволяет ввести два значения через пробел (например, `250.5 3`).
- ⚠️ **Логическая ошибка:** `serviceFee = 20.0` в формуле `portionPrice * portionCount * serviceFee` выглядит как умножение на 20, а не как надбавка в 20 рублей. Если это фиксированная надбавка, формула должна быть `portionPrice * portionCount + serviceFee`.
- ⚠️ Опечатка в приглашении: `"Prise"` вместо `"Price"`.

## 🔹 3. `discret()` — булевы значения

**Назначение:** читает логическое значение (`bool`) в формате 0 или 1 и печатает его как `true`/`false`.

**Разбор и замечания:**
- `std::cin >> ready` для типа `bool` по умолчанию принимает **только `0` или `1`**.
- `std::boolalpha` — манипулятор потока, который включает текстовый вывод логических значений (`true`/`false` вместо `1`/`0`).

---

## 🔹 4. `thory_one()` — строки (`std::string`)

**Назначение:** демонстрирует три способа инициализации `std::string` и чтение имени пользователя.

**Разбор и замечания:**
- Три формы инициализации (`{}`, `=`, `()`) эквивалентны.
- ⚠️ `std::cin >> name` читает **только до первого пробела**. Если нужно ввести имя с пробелом, следует использовать `std::getline(std::cin >> std::ws, name)`.
- ⚠️ Переменные `message`, `message2`, `message3` объявлены, но не используются — компилятор выдаст предупреждение.

## 🔹 5. `practic()` — «STUDI DAY» (комплексный пример)

**Назначение:** собирает данные об учебном дне (имя, курс, длительности блоков, перерыв, готовность) и выводит отчёт.

**Разбор и замечания:**
- `std::getline(std::cin >> std::ws, name)` — правильный приём: `std::ws` «съедает» пробелы и переводы строк, оставшиеся от предыдущего `cin >>`, иначе `getline` прочитает пустую строку.
- Переменная `Total` вычисляется, но **не выводится** — либо используйте её в выводе, либо удалите.
- ⚠️ Опечатка: `"Firt_block"` вместо `"First_block"`.
- ⚠️ В выводе нет пробелов/разделителей: `"Name" << name` даст `NameИван`. Лучше использовать `"Name: " << name`.
- ⚠️ Имена переменных `First_block`, `Break` — стиль не единый (обычно `firstBlock`, `breakTime`; `Break` вообще конфликтует по смыслу с ключевым словом `break`).

## 🔹 6. `dicriment()` — постдекремент

**Назначение:** показывает разницу между постдекрементом `a--` и предекрементом `--a`.

**Разбор и замечания:**
- `b = a--` — сначала `b` получает текущее значение `a` (8), затем `a` уменьшается на 1.
- Итог: `a = 7`, `b = 8`.
- 💡 Замените `std::endl` на `"\n"` — `endl` дополнительно сбрасывает буфер и работает медленнее.

---

## 🔹 7. `calculator()` — простой калькулятор

**Назначение:** выполняет арифметические операции (`+`, `-`, `*`, `/`) над двумя целыми числами.

**Разбор и замечания:**
- Классическая цепочка `if / else if / else` — читаемая и достаточная для 4 операций.
- Защита от деления на ноль реализована корректно.
- ⚠️ **Важно:** целочисленное деление `num1 / num2` отбрасывает дробную часть (например, `7 / 2 == 3`). Если нужен точный результат — используйте `double` или `static_cast<double>(num1) / num2`.
- ⚠️ В исходном файле **не хватает закрывающей `}`** — функция не скомпилируется.
- 💡 Функция объявлена как `int`, но ничего не возвращает. Замените на `void` или добавьте `return 0;`.

## 💻 Точка входа (main)

Код с меню выбора для запуска любой из описанных выше функций:

```cpp
// ---------- main ----------
int main() {
    int choice{};
    std::cout << "Выберите пример:\n"
              << "1 - age\n"
              << "2 - tasc\n"
              << "3 - discret\n"
              << "4 - thory_one\n"
              << "5 - practic\n"
              << "6 - dicriment\n"
              << "7 - calculator\n"
              << "> ";
    std::cin >> choice;

    switch (choice) {
        case 1: age();        break;
        case 2: tasc();       break;
        case 3: discret();    break;
        case 4: thory_one();  break;
        case 5: practic();    break;
        case 6: dicriment();  break;
        case 7: calculator(); break;
        default: std::cout << "Нет такого пункта\n";
    }

    return 0;
}
