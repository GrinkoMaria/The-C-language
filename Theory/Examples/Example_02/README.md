# Разбор кода: Циклы, ветвления и работа с потоками

## Функция `razbor_endl`

```cpp
int razbor_endl() {
    int n{ 21 };
    if (n > 22) {
        std::cout << "n > 22" << std::endl;
    }
    else {
        std::cout << "n <= 22" << std::endl;
    }
}
```

Ожидаемый вывод:

```
n <= 22
```

Теория:
`std::endl` — это не просто перенос строки, а манипулятор, который делает две вещи: вставляет символ `\n` и принудительно очищает буфер вывода (flush). Из-за этого программа делает системный вызов, заставляя консоль немедленно отобразить текст. В консольных приложениях это избыточно: если использовать `std::endl` в цикле на миллион итераций, программа замедлится. Символ `\n` просто добавляет байт в буфер и работает быстрее. Используй `std::endl` только там, где нужна мгновенная очистка (например, перед аварийным завершением), а в остальных случаях хватает `\n`.

Ошибка в коде: Функция возвращает `int`, но не содержит `return`. Это приведет к неопределенному поведению при попытке использовать её результат. Нужно добавить `return 0;` в конец функции.

## Функция `examples`

```cpp
int examples()
{
    char reply{};
    int count{};
    double number{};
    double total{};
    do
    {
        std::cout << "Enter a number: ";
        std::cin >> number;
        total += number;
        ++count;
        std::cout << "Finish? (y/n): ";
        std::cin >> reply;
    } while (reply != 'y' && reply != 'Y');

    std::cout << "The average value is " << total / count << std::endl;
    return 0;
}
```

Ожидаемый вывод (пример):

```
Enter a number: 10
Finish? (y/n): n
Enter a number: 20
Finish? (y/n): y
The average value is 15
```

Теория:
Цикл `do-while` сначала выполняет тело, а потом проверяет условие. Это гарантирует, что пользователь введет хотя бы одно число. Переменная `total` накапливает сумму, а `++count` считает количество вводов. Условие `reply != 'y' && reply != 'Y'` использует логическое «И», чтобы цикл продолжался, пока пользователь не введет `y` в любом регистре. Это классический пример интерактивного ввода с накоплением данных.

Ошибка в коде: Если пользователь при первом же запросе введет `y`, то цикл завершится, и программа попытается выполнить `total / count`. Но `total` будет 0, а `count` будет 1. Это не ошибка, но результат будет 0. Серьезной ошибки здесь нет.

## Функция `cycle`

```cpp
int cycle() {

    switch (x)
    {
    case 1:
        std::cout << "x = 1" << "\n";
        break;
    case 2:
        std::cout << "x = 2" << "\n";
        break;
    case 3:
        std::cout << "x = 3" << "\n";
        break;
    }
}
```

Ожидаемый вывод (при x = 2):

```
x = 2
```

Теория:
`switch-case` — это альтернатива длинной цепочке `if-else`. Он читается лучше, когда у нас много вариантов выбора, и компилятор может оптимизировать его через таблицу переходов. Главное правило: в конце каждого `case` нужно ставить `break`, иначе программа «провалится» в следующий блок. Ограничение: `switch` работает только с целочисленными типами и символами, но не со строками или дробными числами.

Ошибка в коде: Переменная `x` не объявлена и не передается в функцию. Код не скомпилируется, пока не добавить `int x = 2;` перед `switch` или не сделать `x` параметром функции. Также функция не возвращает значение, хотя объявлена как `int`.

## Функция `portion`

```cpp
int portion() {
    const double serviceFee{ 20.0 };
    double portionPrice{};
    int portionCount{};

    std::cout << "Price and portions: ";
    std::cin >> portionPrice >> portionCount;
    double total{ portionPrice * portionCount + serviceFee };
    std::cout << "Total: " << total << " RUB\n";

    return 0;
}
```

Ожидаемый вывод (при вводе 100 и 2):

```
Price and portions: 100 2
Total: 220 RUB
```

Теория:
Здесь мы закрепляем работу с типами данных. Ключевое отличие от предыдущих примеров — формула. Сервисный сбор `serviceFee` прибавляется как фиксированная сумма, а не умножается. Это показывает, как один математический оператор полностью меняет логику. Ввод двух чисел через цепочку `std::cin >> a >> b` — стандартный прием.

Ошибка в коде: Ошибок нет, логика корректна для фиксированного сбора.

## Функция `algebra`

```cpp
int algebra() {
    bool ready{};

    std::cout << "Ready (0 or 1): ";
    std::cin >> ready;
    std::cout << "Ready: " << std::boolalpha << ready << "\n";

    return 0;
}
```

Ожидаемый вывод (при вводе 1):

```
Ready (0 or 1): 1
Ready: true
```

Теория:
Этот пример для практики работы с `bool` и `std::boolalpha`. Манипулятор переключает вывод логических значений с 1 и 0 на `true` и `false`. После первого использования он действует на весь последующий вывод, делая его более читаемым.

Ошибка в коде: Ошибок нет.

## Функция `message`

```cpp
int message() {

    std::string name;
    std::string message{ "Hello NETANIT.COM" };
    // Или так
    std::string mssage2 = "Hello NETANIT.COM";
    std::string message3("Hello NETANIT.COM");

    std::cin >> name;
    std::cout << "Name: " << name << "\n";
}
```

Ожидаемый вывод (при вводе Ivan):

```
Ivan
Name: Ivan
```

Теория:
Повторение способов инициализации строк для практики. Все три синтаксиса создают строку с текстом. Ввод через `std::cin >> name` читает только до первого пробела, поэтому ввести «Ivan Petrov» не получится — в переменную попадет только «Ivan».

Ошибка в коде: Функция объявлена как `int`, но не содержит `return`. Компилятор выдаст предупреждение или ошибку. Кроме того, опечатка в имени переменной `mssage2` — она создана, но нигде не используется. На работу программы это не влияет, но в реальном коде следует избегать мусорных переменных.

## Функция `fullName`

```cpp
int fullName() {

    std::string Full name;

    std::cout << "Full name: ";
    getline(std::cin >> std::ws, fullName);
    std::cout << "Name received: " << fullName << "\n";

    return 0;
}
```

Ожидаемый вывод (при вводе Ivan Petrov):

```
Full name: Ivan Petrov
Name received: Ivan Petrov
```

Теория:
`std::getline` читает строку целиком, включая пробелы. Манипулятор `std::cin >> std::ws` перед вызовом `getline` удаляет оставшийся от предыдущего ввода Enter, иначе `getline` прочитает пустую строку. Это важный прием при комбинировании разных методов ввода.

Ошибка в коде: В строке `std::string Full name;` пробел в имени переменной недопустим — компилятор выдаст синтаксическую ошибку. Правильно: `std::string fullName;`. Также перед `getline` отсутствует `std::`, поэтому нужно писать `std::getline(...)`.
