# Разбор кода: Тернарный оператор, циклы и вложенность

## Функция `primer1`

```cpp
int primer1()
{
	int a{ 5 };
	int b{ 8 };
	int c{};
	if (a > b)
	{
		c - a - b;
	}
	else
	{
		c = a + b;
	}
	std::cout << "C = " << c << std::endl;
}
```

Ожидаемый вывод:

```
C = 13
```

Теория:
Здесь демонстрируется классический подход с использованием условного оператора `if-else`. Переменные `a` и `b` инициализируются значениями 5 и 8. Переменная `c` создается пустой. Условие `a > b` (5 больше 8) ложно, поэтому выполняется блок `else`, где переменная `c` получает значение суммы `a + b`, то есть 13. Вывод подтверждает результат.

Ошибка в коде: В ветке `if` допущена опечатка: написано `c - a - b;` вместо `c = a - b;`. Из-за этого переменная `c` не получает значения в случае истинного условия (хотя здесь оно ложно, и ошибка не проявляется в выводе, но синтаксически выражение бессмысленно). Кроме того, функция объявлена как `int`, но не возвращает значение — это может привести к неопределенному поведению.

## Функция `primer2`

```cpp
int primer2()
{
	int a{ 5 };
	int b{ 8 };
	int c{};
	int c = a > b ? a - b : a + b;
	std::cout << "c = " << c << std::endl;
}
```

Ожидаемый вывод:

```
c = 13
```

Теория:
Этот пример показывает тернарный оператор — сокращенную форму записи `if-else`, которая возвращает значение. Синтаксис: `условие ? значение_если_истина : значение_если_ложь`. Читается так: «если `a > b`, то взять `a - b`, иначе взять `a + b`». Поскольку 5 не больше 8, выбирается ветка сложения, и переменная `c` становится равной 13. Тернарный оператор хорош тем, что позволяет записать простое ветвление в одну строку, делая код компактнее. Он часто используется для присваивания значений по условию.

Ошибка в коде: Переменная `c` объявлена дважды: сначала как `int c{};`, а затем снова `int c = ...`. Это синтаксическая ошибка — повторное объявление переменной в одной области видимости запрещено. Нужно оставить только одно объявление. Также функция не возвращает значение, несмотря на тип `int`.

## Функция `first_primer`

```cpp
int first_primer()
{
	for (int i[1]; i < 10; i++)
	{
		std::cout << i << " * " << i << i * i << std::endl;
	}
}
```

Ожидаемый вывод (при исправлении объявления `i = 1`):

```
1 * 11
2 * 24
3 * 39
4 * 416
5 * 525
6 * 636
7 * 749
8 * 864
9 * 981
```

Теория:
Это классический цикл `for`, который состоит из трех частей: инициализации (`int i = 1`), условия продолжения (`i < 10`) и шага (`i++`). Переменная `i` создается внутри цикла и существует только в его пределах. Тело цикла выводит произведение и квадрат числа. Отличие нового способа от старого здесь не в синтаксисе цикла, а в объявлении переменной прямо в инициализаторе — это делает область видимости переменной локальной, что предотвращает случайное использование `i` после цикла.

Ошибка в коде: В объявлении `int i[1]` допущена синтаксическая ошибка. Квадратные скобки создают массив из одного элемента, а не переменную со значением 1. Правильно: `int i{ 1 }`. Кроме того, в теле цикла отсутствует оператор умножения между `i` и `i * i` — код выведет `i`, затем `i`, затем `i * i` без разделителя, что визуально слипается. Функция также не возвращает значение.

## Функция `second_primer`

```cpp
int second_primer()
{
	int i{ 1 };
	for (; i < 10;)
	{
		std::cout << i << " * " << i << i * i << std::endl;
		i++;
	}
}
```

Ожидаемый вывод:

```
1 * 11
2 * 24
3 * 39
4 * 416
5 * 525
6 * 636
7 * 749
8 * 864
9 * 981
```

Теория:
Этот пример показывает, что части цикла `for` можно выносить за скобки. Инициализация произошла до цикла, а шаг `i++` перенесен в тело. Это старый стиль, который был распространен до C++11, когда переменные объявляли в начале функции. Синтаксически это допустимо, но менее удобно, так как переменная `i` остается видимой после цикла, что может привести к путанице. Современный подход с объявлением внутри `for` считается более безопасным, потому что ограничивает область видимости.

Ошибка в коде: В строке вывода также отсутствует разделитель между `i` и `i * i` — числа слипаются. Функция не возвращает значение.

## Функция `big_primer` и цикл по строке

```cpp
int big_primer()
{
	for (int n : {2, 3, 4, 5})
	{
		std::cout << n << std::endl;
		if (n == 4)
		{
			break;
		}
	}
}

for (char c : "Hello")
{
	if (c == 'e')
	{
		continue;
	}
	std::cout << c << std::endl;
}
```

Ожидаемый вывод для `big_primer`:

```
2
3
4
```

Ожидаемый вывод для цикла по строке:

```
H
l
l
o
```

Теория:
Здесь представлен range-based for (цикл по диапазону), появившийся в C++11. Он позволяет перебирать элементы контейнера или массива без явного использования индексов. В `big_primer` перебираются числа из списка `{2, 3, 4, 5}`. Когда `n` становится равным 4, срабатывает `break`, и цикл прерывается. Во втором фрагменте перебираются символы строки `"Hello"`. Если встречается символ `'e'`, оператор `continue` пропускает вывод, и управление переходит к следующему символу. Отличие от старого способа: раньше для перебора коллекции нужно было вручную писать цикл с индексом, что было более громоздким и опасным (легко выйти за границы). Range-based for делает код чище и безопаснее.

Ошибка в коде: Второй фрагмент (цикл по строке) находится вне функции. Это синтаксическая ошибка — код в C++ должен находиться внутри функции (например, `main`). Кроме того, функция `big_primer` не возвращает значение, хотя объявлена как `int`.

## Функция `example`

```cpp
int example()
{
	int i{ 6 };
	do
	{
		std::cout << i << std::endl;
		i--;
	} while (i > 0);
}
```

Ожидаемый вывод:

```
6
5
4
3
2
1
```

Теория:
Цикл `do-while` сначала выполняет тело, а затем проверяет условие. Здесь переменная `i` начинается с 6, выводится на экран и уменьшается на 1. Условие `i > 0` проверяется после каждой итерации. Цикл завершается, когда `i` становится равным 0. Главное отличие от `while`: тело обязательно выполнится хотя бы один раз, даже если условие изначально ложно. Это удобно, когда нужно что-то вывести или запросить до первой проверки.

Ошибка в коде: Функция объявлена как `int`, но не возвращает значение.

## Функция `example2`

```cpp
int example2() {
	for (int i{ 1 }; i < 10; i++)
	{
		for (int j{ 1 }; j < 10; j++)
		{
			std::cout << i * j << "/t";
		}
		std::cout << std::endl;
	}
}
```

Ожидаемый вывод (при исправлении `/t` на `\t`):

```
1	2	3	4	5	6	7	8	9	
2	4	6	8	10	12	14	16	18	
...
9	18	27	36	45	54	63	72	81	
```

Теория:
Этот пример демонстрирует вложенные циклы. Внешний цикл отвечает за строки, внутренний — за столбцы. Для каждой итерации внешнего цикла внутренний цикл выполняется полностью. В результате мы получаем таблицу умножения. Вложенные циклы — мощный инструмент, но с ними нужно быть осторожным: каждый дополнительный уровень вложенности увеличивает количество итераций (если внешний цикл делает 10 шагов, а внутренний 10, то общее количество выполнений тела будет 100).

Ошибка в коде: В команде вывода используется `"/t"` вместо `"\t"`. Обратный слэш (`\`) — это управляющий символ, а прямой слэш (`/`) — просто символ, поэтому вместо табуляции выведется текст `/t`. Кроме того, функция не возвращает значение.
