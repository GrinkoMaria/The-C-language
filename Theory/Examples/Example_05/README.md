# Разбор кода: Массивы, структуры, перечисления и области видимости

## Функция `first`

```cpp
int first()
{
    int numbers[4]{ 1, 2, 3, 4 };
    int first = numbers[0];
    std:cout << first << std::endl;
    numbers[0] = 34;
    std::cout << numbers[0] << std::endl;

    const int numbers[4]{1, 2, 3, 4}
}
```

Ожидаемый вывод (при исправлении опечаток):

```
1
34
```

Теория:
Здесь мы знакомимся с массивами. Массив — это набор переменных одного типа, расположенных в памяти друг за другом. Запись `int numbers[4]{ 1, 2, 3, 4 };` создает массив из четырех целых чисел. Обращение к элементам идет по индексу, который начинается с нуля: `numbers[0]` — это первый элемент (единица). Мы сохраняем его в переменную `first`, выводим на экран, затем меняем значение `numbers[0]` на 34 и выводим снова.
Константный массив `const int` запрещает изменять свои элементы. Это полезно, когда данные должны оставаться неизменными.

Ошибка в коде: В строке `std:cout` пропущено второе двоеточие, правильно — `std::cout`. В конце функции не хватает точки с запятой после объявления константного массива и отсутствует `return 0;`. Кроме того, переменная `numbers` объявлена дважды в одной области видимости — это ошибка компиляции.

## Функция `second` (и вложенные определения)

```cpp
int second() {
    int numbers[]{ 11, 12, 13, 14 };
    int count = std::size(numbers);
    std::cout << "Length: " << count << std::endl;
    std::cout << "length: " << sizeof(numbers) / sizeof(numbers[0]) << std::endl;

    int numbers[]{ 1, 2, 3, 4 };
    for (int n : numbers) {
        std::cout << n << std::endl;
    }
```

Ожидаемый вывод:

```
Length: 4
length: 4
1
2
3
4
```

Теория:
Здесь показаны два способа узнать размер массива. Функция `std::size` (появилась в C++17) возвращает количество элементов. Старый способ — разделить общий размер массива в байтах (`sizeof(numbers)`) на размер одного элемента (`sizeof(numbers[0])`). Оба подхода дают верный результат.
Цикл `for (int n : numbers)` — это современный цикл по диапазону, который перебирает все элементы массива по очереди. Это гораздо удобнее и безопаснее, чем цикл с индексом, так как мы не можем случайно выйти за границы массива.

Ошибка в коде: Массив `numbers` объявлен дважды в одной функции — это ошибка. Вторая часть с комментариями (структуры, перечисления и т.д.) находится внутри функции `second`, но имеет вложенные функции и `#include`, что недопустимо. Код в таком виде не скомпилируется.

## Структуры и перечисления (вложенный код)

```cpp
    struct person {
        unsigned age;
        std::string name;
    };

    int example() {
        int abc;
        person tom;
        tom.name = "Tom";
        tom.age = 34;
        std::cout << "name: " << tom.name << "\tAge: " << tom.age << std::endl;

        person adam{ 26, "Adam" };
    }
```

Теория:
Структура — это шаблон, который объединяет разные переменные в одну группу. Мы создаем тип `person` с полями `age` и `name`. Затем объявляем переменную `tom` этого типа и заполняем её поля. Можно также инициализировать структуру сразу списком: `person adam{ 26, "Adam" };`. Это позволяет хранить связанные данные вместе.

```cpp
    enum class Day { Monday = 1, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday };
    enum class Operation : char { Add = '+', Subtract = '-', Multiply = '*' };
```

Перечисление (`enum class`) — это тип, который содержит набор именованных констант. `enum class` является строго типизированным: мы не можем случайно сравнить `Day` с `Operation`. Можно задавать базовый тип (например, `char`) и явные значения. В `Day` понедельник равен 1, остальные идут по порядку. В `Operation` символы операций хранятся как `char`.

```cpp
    int today() {
        Day today{ Day::Thursday };
        std::cout << "Today: " << static_cast<int>(today) << std::endl;
```

Здесь мы используем перечисление и преобразуем его в целое число с помощью `static_cast<int>`, чтобы вывести номер дня.

Ошибка в коде: В строке `std::cou` опечатка. В блоке `calculate` опечатка `std::cout < , n1 + n2`. Также в `case Operaton::Subtract` пропущена буква `i`. Вся эта часть кода написана внутри другой функции, что синтаксически неверно.

## Пространства имен, глобальные переменные и функции

```cpp
    namespace settings
 {
    constexpr int minPages{ 1 };
    constexpr int maxPages{ 50 };
    constexpr int PricePerPage{ 4 };
}

bool isValidPsges(int pages)
{
    return pages >= settings::minPages && pages <= settings::maxPages;
}
```

Теория:
Пространство имен (`namespace`) — это способ сгруппировать объявления (переменные, функции, типы), чтобы избежать конфликта имен. Здесь мы создаем пространство `settings`, внутри которого лежат константы, определяющие допустимый диапазон страниц и цену. Обращаться к ним нужно через `settings::minPages`.
Функция `isValidPsges` (опечатка в названии, должно быть `isValidPages`) проверяет, входит ли число страниц в допустимый диапазон. Функция `calculateCost` умножает количество страниц на цену.

```cpp
int counter{ 0 };

int nextNumber()
{
    ++counter;
    return counter;
}
```

Глобальная переменная `counter` объявлена вне функций. Она существует всё время работы программы, и функция `nextNumber` может её изменять. При первом вызове она увеличивается до 1, при втором — до 2. Это демонстрирует, как функции могут изменять глобальное состояние.

```cpp
int calculateCost(int pages)
{
    return pages * 4;
}
void printCost(int cost)
{
    std::cout << "Cost: " << cost << "RUB\n";
}
```

Здесь мы видим перегрузку имени `calculateCost`, хотя в данном случае это просто дублирование функции с тем же именем в разных местах — что вызовет ошибку. Функция `printCost` просто выводит стоимость.

Ошибка в коде: Вся эта часть кода имеет несколько ошибок. Функция `isValidPsges` написана с опечаткой. В конце примера с `validatePages` не хватает `return` для возврата значения типа `PageError`. Также наблюдается дублирование функций `main` и `calculateCost` в одном файле, что недопустимо.

## Функция `validatePages` (фрагмент)

```cpp
enum class PageError { None, TooFew, TooMany };

PageError validatePages(int pages)
{
    std::cout << std::boolalpha;
    std::cout << (validatePages(0) == PageError::TooFew) << "\n";
    std::cout << (validatePages(50) == PageError::None) << "\n";
    std::cout << (validatePages(51) == PageError::TooMany) << "\n";
    return 0;
}
```

Ожидаемый вывод (при корректной реализации проверки):

```
true
true
true
```

Теория:
Здесь демонстрируется использование перечисления `PageError` для возврата кода ошибки из функции. Вместо того чтобы возвращать `bool`, мы возвращаем конкретную причину: `None` (все хорошо), `TooFew` (мало страниц) или `TooMany` (много страниц). Это делает код самодокументируемым и понятным.

Ошибка в коде: Внутри функции `validatePages` вызывается сама же `validatePages(0)`, что приводит к бесконечной рекурсии. Кроме того, функция объявлена как возвращающая `PageError`, но в конце стоит `return 0;`, что является неявным приведением типа (в строгом C++ это может быть ошибкой). Чтобы этот код заработал, нужно реализовать логику проверки и возвращать соответствующие значения `PageError::TooFew`, `PageError::None` или `PageError::TooMany`.
